# Телеграм бот для ведения финансов

## Функционал (первая очередь)
- Учет движения денежных средств (приходы/расходы/перемещения между счетами)
- Хранение и отображение запланированных платежей с напоминалками о предстоящих платежах
- Отображение балансов на счетах с учетом запланированных расходов (сколько "свободных" денег)

## Функционал (вторая очередь)
- Распределение денег по "конвертам" или копилкам для приучения к созданию фондов на разовые крупные расходы, типа страховки, отпуска, лечения и т.п.

## Функционал (третья очередь)
- учет сделок по брокерским счетам
- импорт операций
- импорт журнала сделок по брокерским счетам
- отображение (для акций в портфеле): количество акций, средняя цена покупок/продаж, текущий курс
